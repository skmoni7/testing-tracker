# ProTrack — Free Testing Order Tracker

A Next.js web app for tracking free product testing orders with Firebase backend.

## Stack
- **Frontend**: Next.js 14 (App Router) + Tailwind CSS
- **Auth + DB**: Firebase Authentication + Firestore
- **Hosting**: Vercel
- **Mobile**: Expo (React Native) — base setup in `/mobile`

## Setup
1. Clone the repo and open in GitHub Codespaces
2. Run `npm install`
3. Copy `.env.local.example` to `.env.local` and fill in Firebase credentials
4. Run `npm run dev`

## Deploy
Connected to Vercel — push to `main` auto-deploys to production.
